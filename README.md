# Kleano

Mobile car wash platform.

- `customer-app/` Flutter app for customers
- `biker-app/` Flutter app for bikers
- `dashboard/` React admin dashboard (shadcn, Tailwind, Vite)
- `landing/` Marketing page
- `backend/` NestJS + MongoDB API used by both apps and the dashboard
- `docs/` Design system, handoff notes and backend review
